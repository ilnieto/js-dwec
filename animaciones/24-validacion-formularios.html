¿Cuándo validar un formulario?

El mismo formulario (email + contraseña) validado de cuatro formas distintas: al enviar, al salir de cada campo, en cada tecla, y la estrategia combinada que usan los formularios profesionales.

const form = document.querySelector('form');   form.addEventListener('submit', function(e) {   e.preventDefault();   const errores = validarTodo(); // revisa TODOS los campos   mostrarErrores(errores); });

JavaScript · Event Loop

Asincronía y el Event Loop

setTimeout y fetch no “esperan” dentro de JS: se delegan al navegador (Web APIs) y JS sigue. Cuando terminan, sus callbacks hacen cola — y el event loop decide, con reglas muy concretas, cuándo les toca entrar a la pila.

console.log('1) Empieza el script'); setTimeout(() => log('4) Pasaron 2s (setTimeout)'), 2000); fetch('/datos').then(() => log('3) Llegan los datos (fetch)')); console.log('2) Termina el script (síncrono)');

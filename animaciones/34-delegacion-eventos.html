Delegación de eventos y event.target

En vez de poner un listener en cada botón (que además se crean y destruyen continuamente), se pone uno solo en el contenedor padre. Gracias al bubbling, el clic llega hasta él y event.target le dice qué elemento concreto se pulsó.

✗ Sin delegación — un listener por botón
document.querySelectorAll('.btn-add').forEach(btn => { btn.addEventListener('click', () => { /* … */ }); });
✓ Con delegación — un listener en el padre
catalogo.addEventListener('click', event => { if (event.target.classList.contains('btn-add')) { const id = Number(event.target.getAttribute('data-id')); anadirAlCarrito(id); } });

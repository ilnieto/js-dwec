map · filter · reduce en vivo

Tres funciones de orden superior encadenadas: cada una recibe un array y devuelve algo nuevo, sin tocar el original.

const numeros = [10, 20, 30, 40, 50]; const dobles = numeros.map(n => n * 2); const grandes = dobles.filter(n => n > 50); const total = grandes.reduce((acc, n) => acc + n, 0);

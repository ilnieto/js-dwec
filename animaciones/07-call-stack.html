La pila de llamadas

Cada función que llamas se apila encima de la anterior. Cuando termina, se retira y el control vuelve justo a donde estaba — sin async, sin Web APIs, solo llamadas normales.

function triple(x) { return x * 3; } function calcula(a, b) {   return triple(a) + triple(b); } let total = calcula(2, 5);

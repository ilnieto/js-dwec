Dónde vive cada cosa: pila y heap

No todas las variables se guardan igual. Los primitivos viven dentro del marco de la pila donde se declaran; los objetos, arrays y funciones viven en el heap, y la variable solo guarda una referencia hacia ellos.

function crearUsuario(nombre) {   let activo = true;   let datos = { nombre };   return datos; }   let usuario = crearUsuario('Ana'); console.log(usuario);

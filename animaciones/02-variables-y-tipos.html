Variables y tipos de datos

let y const crean cajas con nombre que guardan un valor. El tipo del valor decide cómo se comporta esa caja — y const, además, no se puede reasignar.

let nombre = "Ana"; let edad = 32; let activo = true; let nada = null; let indefinida; const PI = 3.1416; PI = 3; // intento de reasignar

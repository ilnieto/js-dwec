Set y Map en acción

Un Set solo admite valores únicos. Un Map guarda pares clave-valor en orden de inserción. Compáralos añadiendo y repitiendo entradas.

const numeros = new Set(); numeros.add(1); numeros.add(2); numeros.add(2); // duplicado numeros.add(3);
const persona = new Map(); persona.set('nombre', 'Ana'); persona.set('edad', 32); persona.set('nombre', 'Ana María'); // ya existe

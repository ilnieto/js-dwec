fetch(): pidiendo datos a un servidor

fetch() es la forma moderna de pedir datos por HTTP — y todo lo que toca son promesas: la petición, leer la respuesta, y hasta el error si algo falla.

fetch('https://api.ejemplo.com/usuarios/1')   .then(response => response.json())   .then(data => console.log(data))   .catch(error => console.log('Error de red:', error));

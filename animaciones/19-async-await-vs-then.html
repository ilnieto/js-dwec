async/await: promesas que se leen en síncrono

Mismo resultado, misma espera de fondo — pero async/await hace que el código se lea de arriba a abajo, sin anidar callbacks.

obtenerUsuario()   .then(usuario => obtenerPedidos(usuario))   .then(pedidos => console.log(pedidos))   .catch(error => console.log(error));
usuario: —
pedidos: —
Consola
async function cargarTodo() {   try {     const usuario = await obtenerUsuario();     const pedidos = await obtenerPedidos(usuario);     console.log(pedidos);   } catch (error) { console.log(error); } }
cargarTodo();
usuario: —
pedidos: —

JSON y localStorage

JSON convierte entre objetos y texto. localStorage guarda ese texto en el navegador, sobreviviendo a algo que borra todo lo demás: recargar la página.

const persona = { nombre: 'Ana', edad: 32 }; const texto = JSON.stringify(persona); localStorage.setItem('usuario', texto); // ... el usuario recarga la página ... const guardado = localStorage.getItem('usuario'); const objeto = JSON.parse(guardado);
objeto
{ nombre: 'Ana', edad: 32 }

'{"nombre":"Ana","edad":32}'

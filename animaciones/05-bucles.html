Bucles en acción

for, while, for...of y for...in recorren una colección de formas distintas. Compáralos: mismo resultado, mecánica diferente.

for (let i = 0; i < 4; i++) {   console.log(i); }
Consola
let i = 0; while (i < 4) {   console.log(i);   i++; }
Consola
const frutas = ['manzana', 'plátano', 'uva']; for (const fruta of frutas) {   console.log(fruta); }
Consola
const persona = { nombre: 'Ana', edad: 32, activo: true }; for (const clave in persona) {   console.log(clave, persona[clave]); }
Consola

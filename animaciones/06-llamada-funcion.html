Llamar a una función

Al llamar a una función, el programa salta a su cuerpo, la ejecuta con sus propios parámetros y, al hacer return, el valor vuelve al punto exacto de la llamada.

Código principal
function saluda(nombre) {   return "Hola, " + nombre; } let mensaje = saluda("Marta"); console.log(mensaje);
Dentro de saluda()
function saluda(nombre) {   return "Hola, " + nombre; }

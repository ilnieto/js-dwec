if / else en acción

Un if evalúa una condición y decide qué camino tomar. Solo una de las dos ramas se ejecuta nunca — nunca las dos, nunca ninguna.

let edad = 16; if (edad >= 18) {   console.log("Eres mayor de edad"); } else {   console.log("Eres menor de edad"); }

¿Qué significa "compilado"? C, JavaScript y TypeScript

Un lenguaje compilado revisa los tipos ANTES de ejecutar. JavaScript no revisa nada y ejecuta igual. TypeScript añade esa revisión de tipos... pero por debajo sigue siendo JavaScript.

int sumar(int a, int b) {   return a + b; }   int main() {   printf("%d", sumar(5, "10")); }

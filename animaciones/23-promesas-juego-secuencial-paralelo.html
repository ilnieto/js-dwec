Cargar un juego: uno a uno o todos a la vez

El mismo videojuego cargando jugador, mapa y enemigos — con await secuencial el tiempo se SUMA, con Promise.all solo esperas al recurso más lento.

async function cargarJuego() {   const jugador = await cargarJugador();  // 800ms   const mapa = await cargarMapa();     // 1300ms   const enemigos = await cargarEnemigos(); // 500ms   iniciarPartida(jugador, mapa, enemigos); }

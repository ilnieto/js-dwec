Moverse por el árbol del DOM

parentNode, previousSibling, nextSibling, firstChild, lastChild... y sus versiones con 'Element' — la diferencia está en los nodos de texto que deja el propio HTML.

const pera = document.getElementById('pera');   pera.parentNode;      // → <ul id="lista"> pera.parentElement;   // → <ul id="lista"> (casi siempre igual)   pera.previousSibling;  // → #text (espacio) ⚠️ pera.previousElementSibling; // → <li>Manzana</li>   pera.nextSibling;      // → #text (espacio) ⚠️ pera.nextElementSibling;   // → <li>Plátano</li>   const lista = pera.parentNode; lista.children;        // → HTMLCollection [li, li, li] lista.childNodes;     // → NodeList [text,li,text,li,text,li,text]   lista.firstChild;     // → #text (espacio) ⚠️ lista.firstElementChild; // → <li>Manzana</li> lista.lastChild;      // → #text (espacio) ⚠️ lista.lastElementChild;  // → <li>Plátano</li>
